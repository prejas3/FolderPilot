# Changelog

## 0.2.0

- **New look**: SJ Utility UI (Windows 11 style, shared with Clickloom and Netlume): side navigation (Folders, Rules, Preview, Activity, Settings, About), Mica, light and dark themes, Fluent icons, messages in InfoBars instead of pop-ups, new app icon.
- **Polish and English** everywhere: window, tray menu, rule descriptions, starter rules and error messages. It follows the Windows display language and can be switched in Settings; the choice is kept.
- **Settings**: start with Windows, language, theme, pause all folders (the same switch as in the tray), open the data folder. **About**: version, project page, source, issues, licence.
- Deleting a rule or removing a watched folder can be undone from the message that follows.
- The installer now carries the full licence, copyright and notice texts of everything FolderPilot ships (`THIRD_PARTY_LICENSES.txt`, installed next to the app).
- Rules, watching, moves and undo work as in 0.1.0; `rules.json` from 0.1.0 loads as it is.

## 0.1.0

First release: watched folders, rules (type, name, age, size; move or rename with tokens), preview, journalled moves with undo per run, tray, start with Windows.
